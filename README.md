### Make sure to keep yt-dlp in the same path as the main.exe, and the lib folder!

The goal for this project is for a yt-dlp GUI that is as simple as possible, for users who just want to open an app, paste a link and click a button.

### Simple yt-dlp GUI 

- Supports converting to MKV, Mp4 and Mp3
- Supports playlist toggle
- Supports custom yt-dlp and ffmpeg paths (untested)

Developed and tested on Linux using Pycharm 26.3.

Currently only the windows binary is available under Releases, but a Linux binary will be available soon.

For future versions, two releases will be available. One that includes the Linux yt-dlp binary and one that includes the Windows yt-dlp binary.
